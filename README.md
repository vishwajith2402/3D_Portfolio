## 🚀 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/vishwajith2402/3D_Portfolio.git
   cd 3D_Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

---

## 🌐 Deploy to Vercel

1. Push your repository to GitHub:
   ```bash
   git add .
   git commit -m "feat: complete luxury 3D AI/ML portfolio"
   git push -u origin main
   ```
2. Log in to [Vercel](https://vercel.com).
3. Click **Add New Project** and select `vishwajith2402/3D_Portfolio`.
4. Keep the default Vite build settings:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
5. Click **Deploy**. Any future commit pushed to GitHub will trigger automatic deployments.
